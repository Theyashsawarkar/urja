Changelog

Every change to urja, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

v0.5.02026-11-27Release notes

  • The charge graph is whole on every opening, also after Vyom restarts: with Vyom 0.10 it's Vyom's battery history (UPower's own record, read once, and every change since), with no fetch on opening and no samples of urja's own.
  • The graph no longer goes blank when the charge hasn't moved for 3 hours (plugged in and full): UPower leaves out the point before the window when asked for the window only, so the whole record is asked for and the charge when the window starts carried in.

v0.4.02026-11-27Release notes

  • Opens instantly (first frame 25-70 ms, was 0.5-0.9 s on every opening): the power profile comes from Vyom's live state (power-profiles-daemon's own signals keep it current), not three powerprofilesctl runs (170 ms each) on the main loop; switching it is a D-Bus call that doesn't wait. With an older Vyom it asks the old way.
  • No wakeups while it's hidden: the graph's own charge samples are taken when UPower says the charge or state changed, not every 2 minutes (still every 2 minutes without Vyom's live state).
  • New screenshots in the Spatial look, taken with made-up demo data (WebP, sharp on high-density screens).
  • The website, closer to Vayu's own: the tool's screenshot blurred behind the page, a centred hero with the logo and the verse, the page you're on as the white pill, glass "On this page" and footer panels, releases as cards. No glow behind the logo, no coloured line beside the verse.
  • Spatial look: thicker pill sliders and bars; the profile under the cursor is a light rim.
  • The website has Vayu's Spatial look: graphite glass, a floating navigation bar, near-white for links and the main button, and the tool's own colour only as its signature (the logo's glow, the shloka's line, the release dots). No more all-caps labels.

v0.3.02026-11-09Release notes

  • Where you are on the card is drawn by Vyom core (vk-cursor) instead of urja's own focus watcher; the look is the same.
  • Vim keys (Vyom 0.7): always NORMAL (there's nothing to type); j / k move between the power profiles and the reminder slider, h / l move along the one you're on (a count first: 3l), 0 / $ the slider's ends, Enter picks the focused profile. Space is the leader (Space ? lists every key, q closes) and never presses a control.
  • p switches the power profile (it was documented as P, but Shift never worked). Left / Right now move the control you're on, not always the slider.
  • New keys: 0 turns the reminder off, Space y y copies a summary ("87%, charging, 0.2 h to full"), Space o t opens upower -i in a terminal.
  • Keys are data (urja/vim.py); scripts/keybinds.py writes the # keybind: lines and the README table from it (--check in CI).
  • Needs Vyom 0.7.0.

v0.2.02026-11-07Release notes

  • Time to full or time left is the headline, next to a bigger charge ring that says its state in words ("charging", "on battery", "low").
  • A charge graph of the last 3 hours, from UPower's history (no root needed) and urja's own samples.
  • Power draw in watts, and when the battery doesn't report a current (this HP's doesn't), an estimate from the last half hour, marked "about".
  • Health as a bar with a word: good (green), worn (yellow) or replace (red), with what that means in plain words, cycles and the battery's make.
  • Power profile as a segmented control, the current one filled; P cycles.
  • The charge reminder shows its value in peach and has an 85% stop; a value between stops now lands on the nearest one instead of "off".
  • vyom urja demo shows made-up numbers.
  • Needs Vyom 0.6.0.
  • Every corner is rounded: the website's callouts.

v0.1.42026-11-04Release notes

  • The card stays true while it's open: plug the charger in and it shows within 2 seconds, without disturbing the reminder slider. It used to show the moment you opened it, until you closed it.
  • A logo and a shloka at the top of the README and the website: every Vayu tool has them now.

v0.1.32026-10-21Release notes

  • Follows the theme: its colours are named (@accent, @crust...) instead of fixed hex codes, so a theme that redefines them (Vyom 0.2.9's css, e.g. varna) recolours it too.

v0.1.22026-10-21Release notes

  • A website (GitHub Pages, https://theyashsawarkar.github.io/urja/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.12026-10-21Release notes

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.02026-10-19Release notes

  • First release, as its own repository: the battery at a glance. Replaces battery-limit-picker.py in Vayu.
  • A charge ring, time to full or empty, power draw in watts, the battery's health (of its design capacity) and cycle count.
  • Works with both kinds of battery driver (energy_* / power_now, or charge_* / current_now).
  • The power profile (power-profiles-daemon), switched with a click or P.
  • With limit_file set, a charge-limit reminder slider: the percentage a watcher of yours nudges you to unplug at.
